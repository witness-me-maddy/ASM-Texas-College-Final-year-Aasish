# Contributing

Thanks for contributing to this Attack Surface Management project.

## Development setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run checks

```bash
python -m pytest -q
```

## Coding guidelines

- Keep functions small and testable.
- Add tests for behavior changes.
- Update `README.md` when adding commands/features.

## Pull requests

- Use the PR template.
- Include test output.
- Keep scope focused and clearly explained.
